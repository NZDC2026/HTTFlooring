# ADR-0010：日常开发统一业务库

日期：2026-11-07。决定已批准，实际执行证据见STATUS及数据库文档。

用户确认当前服务器为开发/测试环境，要求人工验收和应用统一使用 `htt_management`。库名Main表示应用业务库，不代表当前环境已是生产。更新ADR-0004及演示数据首轮安排：Main可执行明确授权且标识的开发种子；自动化测试/故障试验仍只能在Validation或Testcontainers执行。

只部署一个HTT业务库即可满足生产运行，Validation不进入生产依赖。Keycloak独立身份存储仍由其部署维护。三端和未来ERP共用Main内相同业务表，不为每个客户端创建库。

生产结构以不可变Flyway V1～V6及后续迁移为准，空库先由环境管理员准备独立运行/迁移角色、数据库和platform schema，再使用独立迁移凭据执行migrate/validate。生产不运行演示数据工具，不从开发库克隆演示账户、权限或库存。API启动继续validate-only，保留RLS及最小运行权限。

代价：隔离测试仍需一套非生产数据库或临时容器，否则失败测试可能影响人工数据。开发演示入口要求精确目标、匹配角色和显式开发写入开关；开关是防误操作措施，不是生产访问控制的替代。

本轮范围及回退见 [实施计划](../plans/development-database.md)；不删旧验证库、不扩展ERPNext访问、不改变前端登录协议。
