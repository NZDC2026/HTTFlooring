# Synthetic compatibility regression

Run from any directory with Docker running, JDK 21 (`JAVA_HOME`), Maven, .NET 10, Flutter, Python 3 and OpenSSL available:

```sh
python3 tests/compatibility/run.py --legacy ../htt-backend --flutter ../htt_flooring_app --gst-basis NON_CASH
python3 tests/compatibility/run.py --legacy ../htt-backend --flutter ../htt_flooring_app --gst-basis CASH
```

Set `HTT_COMPAT_DOTNET` and `HTT_COMPAT_FLUTTER` when those executables are outside PATH. The legacy default also recognizes the eventual literal folder `htt-backend-c#`.

The runner creates a uniquely named disposable PostgreSQL 17 container exposed only on loopback, applies the original SQL migrations and synthetic fixtures, builds Java and isolated copies of the legacy API/Worker and Flutter client, and runs the HTTP comparisons and recovery scenarios. It does not modify either original source tree or connect to production services. The legacy copy accepts only the generated localhost certificate fingerprint. A local scanner fixture replaces ClamAV. Isolated Worker configuration clears mail, OCR, geocoding and push credentials and disables bank feeds. The runner removes its own container and anonymous test data volume on ordinary success/failure; abrupt machine termination may require removing the recorded `htt-java-compat-*` container manually.

Evidence stays in `target/compatibility/<run-id>/`, including build output, HTTP comparison output and server logs. A `PASSED` file is written only after every full-suite assertion succeeds. `--uploads-only` runs focused attachment/authentication checks and writes only `UPLOAD_PASSED`, never full acceptance evidence. Fixture business dates use the synthetic company’s Australia/Sydney timezone, including when the workstation has crossed midnight earlier. Ports 15081, 15082 and 15443 must be free; do not run multiple suites concurrently. Build/package downloads need network access. The expanded suite paces business requests below each backend’s 300/minute limit, so it may pause between batches. Add `--stalled-uploads` to include the optional stalled-body (400 after approximately 6 seconds) and continuous-body absolute deadline (500 after approximately 30 seconds) probes against both servers; the default run skips those probes. Rejected upload keys must not enter idempotency storage.
