## 本批发现与修复

1. **停用仍显示可售量。** 旧库存读取只检查仓库kind，忽略warehouse.active、product.status与sell_enabled。新增3个测试先复现全部失败（预期0，实际10）；修复后保留onHand/reserved、available返回0，隔离仓仍为0。三个客户端未改。
2. **缺少跨模块可重复核对入口。** 新增016与财务只读一致性API，按来源流水重算数量/成本、核对预留/承诺/AR/AP/预收预付/GRNI/采购退货清算及GL。逐实体差异先计数，避免正负相抵；缺估值/缺投影/缺零金额子账明确报告。检查不自动修复或产生补差凭证。
3. **新增API可能对旧库误报ready。** ready探针增加016函数存在要求；升级测试扩至015旧库，保留旧来源、摘要和余额；001—015不改。
4. **阶段完成度缺少统一证据。** 整理116条原需求与W-01—W-06仓管补充，明确“后台完成”与“客户端未联调”、B欠交与C/D未来范围。历史阶段文档中的旧待办不作为当前状态，按本报告和各切片最新说明判断。

未发现本批正常支持场景下的库存、AR/AP/预收预付/GRNI与GL残差。该结论来自新增跨流程和故障注入测试，不能推导为所有未实现交易、真实账套迁移和澳洲税务场景均已验收。
