# Local management report packs

Entry: Report library → Management report packs (`/reports/packs`).

The report-pack register now saves a name, period, cover heading/note and an ordered selection of one to six reports: Profit & loss, Balance sheet, Trial balance, Cash flow, Net sales and Net purchases. Reports can be selected and reordered before saving. Existing revision checks, activation/deactivation, main-owned persistence and configuration history apply. Legacy configurations with unsupported report names remain restorable; they must be edited to supported selections before generation.

Generate reads current main-process repositories and runs the same calculators as the standalone reports. Balance sheet uses the To date; P&L/trial balance and document/cash activity use the saved period. The generated company name/currency, configuration revision, actor, timestamp and values are copied into an independent preview. Renderer-supplied journals, results or actor IDs are rejected. Generation is exposed only on the report-pack repository under accounting.read and is recorded in the trusted security audit. Accountants/auditors may generate; only accounting.post roles may edit configuration. Operational roles cannot generate or read these packs. No new schema or repository is required.

Generation does not create invoices, bills, payments, journals or other financial records. The existing desktop command audit/commit mechanism still runs. Generated previews remain in memory on the detail page; configurations and their history persist across restart. Retain generated copies using CSV, printable HTML or the print dialog's Save as PDF. There is no new durable prepared-pack archive or external delivery service. Source/configuration changes display a stale-copy notice; a refreshed generation is explicit and never silently overwrites the current exported copy.

The printable pack has a cover, ordered contents, section tables, totals and generation context. Print CSS uses A4 portrait, repeating table headers and readable wrapped cells, including the eight-column trial balance. HTML escapes all user text and uses a restrictive CSP with no external content, scripts or forms. CSV includes all selected sections and rows, review notes, period/currency/configuration context and spreadsheet formula protection. Filenames are sanitized. Exported files retain the generated data and do not recalculate when reopened.

Material report boundaries remain visible in each section. Cash flow is the single-company-currency bank ledger working paper, with internal transfers netted and opening adjustments separately identified; other bank currencies are excluded with a review note rather than converted. Document net sales/purchases include saved credits and dated void corrections, excluding opening documents, settlements and manual GL adjustments. Net purchases are not recognized inventory expense. GL differences and unclassified cash movements remain warnings with their real amounts; no balancing figures are invented.

Automated acceptance adds 19 tests in two files: trusted generation and exact agreement with the existing report calculators; net sales/purchase credits; independent copied data and source signatures; refresh/restart; stale/inactive/missing configurations; injected payloads; selection validation and legacy restore compatibility; accounting/audit permissions and operational-role rejection; security audit; period boundaries and reversals; foreign-currency notes; real GL differences; atomic failure of an incomplete pack; safe HTML/CSV and filenames; and zero-activity results.
