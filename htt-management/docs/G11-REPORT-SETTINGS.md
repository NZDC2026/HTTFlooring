# G11 报表设置默认值

G11 本地范围：独立 `/settings/reports` 页面，默认口径、币种偏好、自定义表头、金额小数位，以及报表页面和新生成输出的实际应用链。沿用本地 Repository／Service／快照／审计，没有连接独立后台。

## 配置与含义

- **表头**：最多 160 字符的纯文本；页面、报表包封面及各节、保存报表的 HTML／CSV 使用该值。HTML 转义，CSV 公式注入防护沿用现有输出机制。
- **金额精度**：2、3、4 位小数。金额计算、过账、核销仍按原有分币规则；增加的显示位数不会增加账务精度。数量、计数、天数、百分比和单位成本保留各自含义及原有精度。
- **默认口径**：Accrual 或 Cash。报表库提供兼容口径的默认入口；新保存报表在 Cash 下默认 Banking，新报表包默认只选择 Cash flow。已有定义不改写。损益、资产负债表、总账、试算表、单据分析和子账控制继续明确使用权责／余额口径；银行报表继续现金口径；工资汇总明确为按工资支付日期的运营汇总。没有把 Cash 字样套在权责计算上，也未实现现金制损益换算。
- **币种偏好**：BASE、AUD、NZD。独立现金流／银行汇总及新的 Banking 保存报表可选已有银行币种；偏好币种不存在时回到本位币。财务报表和完整报表包保持公司本位币；显式保存的银行筛选优先于默认值。所有输出声明实际币种，不做 FX 换算，不把外币合并成本位币。工资汇总按所选工资币种筛选后汇总，不混合币种。

## 页面／输出契约

| 报表范围 | 表头与金额显示 | 输出与实际口径 |
| --- | --- | --- |

| AR／AP 账龄、客户／供应商对账单 | 共享表头、金额精度、本位币 | 子账余额；现有打印／客户 PDF 保留页面表头 |

| AR／AP 到 GL、预付款资产、预收款负债、Finance controls | 共享表头、金额精度 | 明确余额／控制口径；现有打印保持表头 |

| 保存报表 | 每次运行保存 presentation 快照 | HTML、CSV、打印使用该次结果，声明 dataset、实际 basis 和 currency |
| 管理报表包 | 每次生成保存公司及 presentation 快照 | 每一节单独说明实际口径；HTML、CSV、PDF 保留生成时的表头与精度，整体本位币 |

## 历史、权限与异常

沿用 `workspace_settings` 的版本校验和可信 actor 审计。维护需要 `accounting.post`（ADMIN／FINANCE_ADMIN／ACCOUNTANT），查看入口需要 `accounting.read`。AUDITOR 只读，SALES／WAREHOUSE／PURCHASING 不能从主进程维护默认值。

设置保存拒绝无效枚举、精度、超长表头、停用和过期 revision；持久化失败回滚设置和审计。重启恢复已提交默认值。快照版本继续为 30：本次新增的是既有设置记录的显式 `reportDefaults` 标记及生成副本中的可选 presentation 字段；旧通用报表设置不自动解释为新规则，旧导出对象缺少 presentation 时固定按原有两位小数渲染，不读取当前设置。

设置变化会使既有内存预览显示来源／定义已变化，但不会重写其结果或导出内容；须重新生成才使用新默认值。HTML／CSV／PDF 导出文件保持原副本。报表定义和本地运行审计持久化，生成结果仍按现有架构通过导出保留，没有新增无界文件存储。
