# G01 Dashboard 银行对账证据

G01 实现完成。Dashboard 使用与关账、恢复相同的只读对账链证明，包含已导入流水的关联、金额和清除证据。输入变化通过现有订阅刷新。

校验失败或抛出异常时，该银行显示“Reconciliation evidence requires review”，附原因和账户链接。整条累计链没有可靠证明时，不采信其中任何清除ID，也不显示未经验证的最后对账日期。行数标为“without verified clearing”，不把历史已经清除的流水重新断言为确定未清除；这是保守的只读显示。真实登记簿金额、分录和已保存对账记录不变。

Tasks & Alerts 单列需复核账户，零流水但对账证据异常时也不显示无待办。正常链仍展示最后已验证日期和真实未清除数；合法未来对账在日期到达前不用于清除。内部抵销行仍不当作外部现金待对账。

新增回归覆盖错误保存余额/差额、未知或重复行、错误状态/日期、重复记录、早期错误被后续零差额掩盖、多账户隔离、零流水异常、已导入流水金额错误、正常历史/未来记录及无副作用。页面渲染验证异常文案、账户导航、提醒与正常状态。现有主进程关账异常测试还核对 Dashboard 状态在异常/恢复后与后端判断一致。

本项不改动账务数据、权限或持久化结构，不自动修复历史错误。G02、G17 及其它缺口保持未关闭。最终实际项目 build/test 及原生检查记录在交付时补充。
