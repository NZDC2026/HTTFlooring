## 共享行为

- DataTable 使用声明的标量访问器搜索、排序与导出；修复未提供分页控件时仍默默截取十行的问题。已有外部筛选继续生效。
- View columns 可隐藏、恢复列；至少保留一个数据列。设置仅在当前视图内生效，不持久化为全局用户策略。
- 稳定且唯一的业务 ID 支持跨页选择；筛选后选择范围与当前数据集取交集。完整导出及选中导出读取全部筛选、排序结果，不读取当前页或 DOM 文本。
- SampleTable 的 ReadOnlyTable 只有在显式提供完整筛选数据集、稳定 ID、标量单元格与读取权限时才开放导出及选择。没有声明完整契约的表格不会冒充全量导出。
- 导出仅含可见且声明允许导出的数据列；操作、选择及内部对象字段不导出。遵守 BOM/CSV 引号、Unicode、换行和公式文本防护，拒绝非法数值及对象。数字负值保留数字语义。
- 权限撤销后停止显示声明数据及导出；业务服务仍先执行原有权限投影。工资导出没有 TFN/银行详情，库存清单不额外暴露成本。

## 受控批量状态

支持任务、促销、单据模板、项目、银行规则、保存的报表定义和报表包定义共七类。主进程按域核对写权限；任务支持 Open/In progress/Completed，其余仅 Active/Inactive。税码、关联科目和财务设置不接受通用批次。

最多 100 条一次，先 Review，再明确 Apply；导出不受此批次上限限制。预览保存每条版本与前后状态，提交重新验证全部版本及领域规则；任何一条失败则整体回滚。请求 ID 与规范化内容形成幂等批次，逐条审计保留可信操作者、时间和批次证据；重启、持久化确认不确定后的重试、冲突、伪造/缺失审计组均有测试。旧批次重试不会覆盖后来单独修改的记录。

预览不改变业务 records/storage，但可信主进程可记录安全审计、命令元数据及保存时间。改变选择会使旧审核失效。规则/模板状态影响后续使用，不改写历史财务快照。

没有加入通用批量过账、付款、作废、永久清理或审批；这些表格继续使用各自具备金额、版本、来源、期间、审批和恢复校验的专用流程。固定报表保留自己的报表导出/打印；不可变文件和审计表保留专用选择、顺序与操作。逐表清单明确这些适用边界。
